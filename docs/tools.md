# Tools

Mechanical steps are scripts, not agents. Every tool runs as `<skill-dir>/scripts/sl <tool> ...`, where `<skill-dir>` is `skills/subagent-driven-development`. The `sl` launcher runs a `.sh` tool under bash and a `.py` tool under the first working Python, and exits 3 when there is none. It caches that interpreter, so each later call is one Python start (`SUPERLITE_PYTHON` skips the probe entirely). Tools that need each other import them in process instead of spawning `sl` again. Bare `sl` lists the tools, and an unknown tool name suggests the nearest. The tools are Python, but the project can be any language.

`sl` runs as an executable (the Claude Code worktree guard refuses `bash <script>`). `Permission denied` or a shell without shebang support, such as PowerShell: prefix `bash`.

`_pyrun.py` is a shared helper, not a tool. Probes live in `probes/` with the probe pack in `probes/pack/`.

The coordinator guard (`hooks/block-coordinator-edits`) judges `cp`, `mv` and `tee` with a directory target (trailing `/`, `.` or an existing directory) by `<dir>/<basename of the first source>`, and resolves `sys.argv[N]` writer targets to the interpreter's N-th positional argument, through one `VAR=literal` assignment in the same command; anything unresolvable still blocks. `pathlib.Path('...')` and a mode-first `Path('...').open('w')` count as writer targets like `Path('...')`. It also judges a stdin shell's heredoc or here-string program, git `checkout`/`restore`/`rm`/`mv`/`clean` paths, `stash pop|apply|branch`, `reset --hard` and forced discards (`checkout -f`, `switch --discard-changes`), and `tar -x`/`unzip` targets ([hooks.md](hooks.md)). It composes a Python string `+` when it resolves a writer target (`open(out+'x.md','w')` with a literal `out`), passes `rm -r` and `rmdir` of an untracked folder that no task owns (a symlink, a hard link, a nested `.git` or `.superlite`, or more than 2000 entries still block), and every block prints `Refused command: <the innermost command> (none of this Bash call ran; run its other commands again without it)` after the policy lines.
